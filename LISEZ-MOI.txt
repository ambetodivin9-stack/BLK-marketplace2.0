ICÔNES BLK MARKETPLACE
======================
À mettre à la RACINE du projet GitHub (à côté de index.html), en remplaçant les anciens fichiers :

  icon-180.png   -> icône iPhone (apple-touch-icon)
  icon-192.png   -> icône Android / manifest.json
  icon-512.png   -> icône Android / manifest.json
  favicon-32.png -> onglet du navigateur
  icon-maskable-512.png -> (facultatif) icône Android qui s'adapte aux formes rondes

Les fichiers n'ont pas de transparence (fond blanc), ce que demande iPhone.

Dans index.html, vérifier ces lignes :
  <link rel="icon" href="favicon-32.png" type="image/png">
  <link rel="apple-touch-icon" href="icon-180.png">

Après envoi sur GitHub et déploiement Vercel :
  1) Sur l'iPhone, supprimer l'ancienne icône BLK de l'écran d'accueil
  2) Rouvrir le site dans Safari, puis refaire : Partager > Sur l'écran d'accueil > Ajouter
(iPhone garde l'ancienne icône en mémoire, c'est pour ça qu'il faut la refaire.)
